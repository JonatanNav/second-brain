# Harvest

The only path from a cell into Core. Each file is a proposed addition, written with
`core/templates/harvest.md` and **anonymised**: no client names, people, or figures that identify a client.

Review flow: `proposed` → you review → `accepted` (content merged into `core/`, file deleted) or `rejected`.

Nothing from a **C3** cell is harvested unless you write the lesson yourself.
